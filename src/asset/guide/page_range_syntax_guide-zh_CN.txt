        页面范围语法指南

1. 原子 (Atoms)
   - 原子是选择页面的最小单位，每个原子生成一组页码。
   - 单个页码: "2" -> {2}
   - 连续范围: "3-10" -> {3, 4, 5, 6, 7, 8, 9, 10}，起始、结束可以省略
     - 省略结束页码: "10-" -> {10, 11, ..., 最后一页}
     - 省略起始页码: "-20" -> {1, 2, ..., 20}
     - 二者都有省略："-" == 全部页面
   - 带步长的范围 (A-B:S):
     - 从 A 到 B，按步长 S 取页："3-10:3" -> {3, 6, 9}，起始、结束可以省略
     - 全文档步进 (-:S/:S): 全文档范围内，每隔 S 页取一页，":3" -> {1, 4, 7, 10, ...}

2. 组合 (Compositions)
   - 用逗号 "," 连接多个原子，将它们的页码合并成一个序列。
   - 示例: "5,1-10:3"
     - 原子 "5" -> {5}
     - 原子 "1-10:3" -> {1, 4, 7, 10}
     - 合并后 -> {5, 1, 4, 7, 10}
     - 在默认模式下，该结果会被去重并升序排列，见第4节。

3. 分组 (Groups)
   - 用分号 ";" 分隔不同的组合，每个组合会单独生成一个 PDF 文件。
   - 示例: "5,1-10:3;20-30;1-5"
     - 文件 1: 组合 "5,1-10:3" 的结果
     - 文件 2: 原子 "20-30" 的结果
     - 文件 3: 原子 "1-5" 的结果

4. 默认模式 (Default Mode)
   - 未加特殊前缀时的默认行为。
   - 去重: 自动移除所有重复页码。
   - 排序: 所有页码强制按升序排列，不保留输入顺序。
   - 限制: 禁止使用反向范围 (如 "9-5")，否则会报错。

5. 增强模式 (Plus Mode)
  - 激活方式: 表达式以加号 "+" 开头，仅允许在字符串最前端，否则报错。
  - 允许重复: 页码可以多次出现，不做去重处理。
  - 保留书写顺序: 严格按照表达式中的顺序输出页码，不强制升序。
  - 允许反向范围: 支持降序范围，如 "+9-5"。
  - 示例:
    - "+4-8,6,9" -> {4, 5, 6, 7, 8, 6, 9}
    - "+9-5" -> {9, 8, 7, 6, 5}
